# Tempo

A local League of Legends and TFT companion for Windows 10/11 (64-bit).

## Install

1. Open [the latest release](https://github.com/ivanhirskyy/tempo-releases/releases/latest).
2. Download **Tempo_x.y.z_x64-setup.exe** and run it.
3. If Windows SmartScreen appears, choose **More info → Run anyway**.

No GitHub account, developer tools or administrator access needed. WebView2 is installed if missing (internet access required). Open League and Tempo to get started.

## Update

Tempo checks at launch and every four hours. You can also click **Check for updates** in the sidebar. When a release is available, click **Update to v…**. Tempo downloads the signed installer, closes, installs and reopens. Installation is disabled during champ select and games. Local settings and history stay on your computer.

If an update fails, retry or download the latest installer here and run it over the existing installation.
